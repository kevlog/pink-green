## 🎨 Brave Pink Hero Green Generator

Brave Pink Hero Green (BPHG) Generator adalah alat web sederhana dan cepat untuk mengubah foto menjadi efek duotone khas Brave Pink Hero Green. Aplikasi ini berjalan sepenuhnya di *browser* Anda, memastikan privasi dan keamanan data Anda karena tidak ada data yang diunggah ke server.

### ✨ Fitur Utama

  * **Filter Duotone Instan**: Ubah foto Anda dengan kombinasi warna ikonik **pink** (`#f784c5`) dan **hijau** (`#1b602f`).
  * **Editor Interaktif**: Sesuaikan warna duotone dan intensitas efek secara langsung.
  * **Unggah Gambar Fleksibel**: Unggah gambar dengan mudah melalui tombol "Pilih Gambar" atau cukup seret dan lepas (*drag and drop*) file Anda ke dalam aplikasi.
  * **Proses Aman**: Semua pemrosesan gambar dilakukan di sisi klien (*client-side*), sehingga foto Anda tidak pernah meninggalkan komputer Anda.
  * **Unduh Cepat**: Simpan gambar hasil edit Anda dalam format PNG dengan satu klik.

-----

### 💻 Teknologi yang Digunakan

Proyek ini dibangun menggunakan teknologi web modern:

  * **HTML5**: Struktur dasar halaman.
  * **CSS3**: Penataan visual.
  * **Tailwind CSS**: Kerangka kerja CSS untuk desain yang cepat dan responsif.
  * **JavaScript (ES6+)**: Logika inti dan manipulasi DOM.
  * **GSAP (GreenSock Animation Platform)**: Untuk animasi judul yang interaktif dan halus.
  * **Particles.js**: Efek partikel interaktif di latar belakang.
  * **SweetAlert2**: Notifikasi dan *pop-up* yang elegan dan kustomisasi.

### 🚀 Cara Menggunakan (Untuk End User)

1.  Buka alamat yang ada di deskripsi repo ini.
2.  Unggah foto dengan salah satu cara berikut:
      * Klik area "Pilih gambar atau seret di sini" dan pilih file dari komputer Anda.
      * Seret dan lepas file gambar langsung ke area tersebut.
3.  Setelah gambar diunggah, gunakan kontrol di panel kanan untuk menyesuaikan efek duotone:
      * **Warna 1 (Pink)**: Mengubah warna terang pada gambar.
      * **Warna 2 (Hijau)**: Mengubah warna gelap pada gambar.
      * **Intensitas Duotone**: Mengatur seberapa kuat efek duotone.
4.  Klik tombol **"Download"** untuk menyimpan gambar hasil edit ke perangkat Anda.
5.  Klik tombol **"Reset"** untuk menghapus gambar dan mengembalikan pengaturan ke awal.

-----

### 🔧 Instalasi (Untuk Pengembang)

Proyek ini tidak memerlukan *setup* backend. Anda bisa menjalankannya langsung di *browser*.

1.  Cloning repositori ini ke komputer Anda:
    ```bash
    git clone https://github.com/kevlog/pink-green
    ```
2.  Buka folder proyek:
    ```bash
    cd pink-green
    ```
3.  Buka file `index.html` di *browser* favorit Anda.
